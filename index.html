🛠️ Pre-Workshop Setup

Complete this before the workshop so we can start coding immediately.

1️⃣ Check if you have Node.js

Open your terminal (macOS/Linux) or PowerShell (Windows) and run:

node --version

If you see a version number (v20.x.x or higher): You have Node.js. Skip to Step 2.

If you get an error: Install Node.js first.

macOS

Download the LTS installer from nodejs.org and run it.

Or if you have Homebrew:

brew install node
Windows

Download the LTS installer from nodejs.org.

Click through the installer with default settings, then restart PowerShell.

Linux

Use your package manager. For Ubuntu/Debian:

sudo apt update && sudo apt install nodejs npm

2️⃣ Install OpenCode

With Node.js installed, run this command:

npm install -g opencode-ai

Wait for it to complete. This installs the OpenCode CLI tool.

3️⃣ Verify installation

opencode --version

If you see a version number, you are ready for the workshop.

🩹 Troubleshooting

Command not found (macOS/Linux)

Your npm global packages may not be in your PATH. Add this to your shell config:

export PATH="$PATH:$(npm config get prefix)/bin"

Then restart your terminal or run source ~/.bashrc (or ~/.zshrc).

Permission denied (macOS/Linux)

Use a Node version manager or fix npm permissions. Quick fix:

sudo npm install -g opencode-ai
PowerShell execution policy (Windows)

If npm commands fail, you may need to set execution policy:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

📚 Workshop Resources

🔑 Get a free API key (choose one)

🌟 Google AI Studio (Recommended)

Free tier: 1,500 requests per day on Gemini 2.5 Pro

  1. Go to aistudio.google.com/app/apikey
  2. Click "Create API key"
  3. Copy your key
  4. In your terminal, run: export GEMINI_API_KEY=your-key-here

🔌 OpenRouter

Free tier: Access to Claude, GPT-4o, Llama with rate limits. Starts with $5-10 credit.

  1. Sign up at openrouter.ai
  2. Go to Settings → API Keys
  3. Create a key
  4. In your terminal, run: export OPENROUTER_API_KEY=your-key-here

⌨️ Live Reference

Quick commands to use during the workshop.

🚀 Starting OpenCode

# With built-in free tier
opencode

# With Gemini
export GEMINI_API_KEY=your-key
opencode

# With OpenRouter
export OPENROUTER_API_KEY=your-key
opencode

⚡ Essential Commands

Command What it does
/help Show all available commands
/cost Check your token usage and cost
/undo Revert the last change
/models List available AI models
Ctrl+C Cancel the current AI request

🔄 Model switching

# Inside OpenCode, switch models with:
/model gemini-2.5-pro

# Or for OpenRouter:
/model openrouter/anthropic/claude-3.5-sonnet

⏱️ Free tier limits

  • Google AI Studio: 1,500 requests/day
  • OpenRouter free: Rate limited, $5-10 starting credit
  • OpenCode built-in: ~50 messages/day

If you hit limits, switch providers or wait for the next day.
