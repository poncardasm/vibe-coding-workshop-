🛠️ Pre-Workshop Setup

Complete this before the workshop so we can start coding immediately.

1️⃣ Download OpenCode Desktop

OpenCode Desktop is a free app that lets you code with AI. No terminal required.

Download OpenCode Desktop

macOS

Download the .dmg file, open it, and drag OpenCode to your Applications folder.

First launch: Right-click the app → Open (may show security warning for unsigned apps).

Windows

Download the .exe installer and run it. Follow the installation wizard.

Windows Defender may warn about unverified publisher — click "More info" → "Run anyway".

Linux

Download the AppImage or .deb/.rpm package for your distribution.

For AppImage: Right-click → Properties → Allow executing as program. Then double-click to run.

2️⃣ Launch and configure

Open the app. You'll see a setup screen asking for an API key.

For now, skip this. Click "Continue with free tier" or "Skip" to use OpenCode's built-in free models.

3️⃣ Verify it works

Click "New Chat" and type: hello, can you help me learn coding?

If you get a response, you're ready for the workshop.

🩹 Troubleshooting

App won't open (macOS security)

Go to System Preferences → Security & Privacy → General. Click "Open Anyway" next to the OpenCode message.

Windows Defender blocked it

Click "More info" on the warning dialog, then "Run anyway". This is normal for new open-source apps.

Linux AppImage won't run

Right-click the AppImage file → Properties → Permissions → Check "Allow executing file as program". Then double-click.

📚 Workshop Resources

🔑 Upgrade to better AI (optional)

The built-in free tier is fine to start. To use stronger models like Gemini 2.5 Pro or Claude 3.5:

🌟 Google AI Studio (Recommended)

Free tier: 1,500 requests per day on Gemini 2.5 Pro

  1. Go to aistudio.google.com/app/apikey
  2. Click "Create API key"
  3. Copy your key
  4. In OpenCode Desktop: Settings → API Keys → Add Gemini key

🔌 OpenRouter

Free tier: Access to Claude, GPT-4o, Llama with rate limits. Starts with $5-10 credit.

  1. Sign up at openrouter.ai
  2. Go to Settings → API Keys
  3. Create a key
  4. In OpenCode Desktop: Settings → API Keys → Add OpenRouter key

⌨️ Live Reference

Quick guide for during the workshop.

🚀 Starting a session

Click "New Chat" or open a folder from the home screen. The AI will see your files and help you code.

⚡ Essential commands

Type these in the chat box:

Command What it does
/help Show all available commands
/cost Check your token usage
/undo Revert last code change
/models See available AI models
Ctrl+C Stop the AI mid-response

🔄 Switching models

In the chat, type:

/model gemini-2.5-pro

Or click the model name in the top bar and select from the dropdown.

⏱️ Free tier limits

  • OpenCode built-in: ~50 messages/day
  • Google AI Studio: 1,500 requests/day
  • OpenRouter free: Rate limited, $5-10 starting credit

Hit a limit? Switch providers in Settings or wait for the next day.
